Anthropic Claude Code 源码泄露事件 —— AI 界"核泄漏"

Critical 🌍 全球 AI 社区
  • 时间: 2026 年 3 月 31 日
  • 风险等级: 🔴 严重
  • 事件概述: Anthropic 在 npm 发布 Claude Code v2.1.88 版本时，因构建流程配置失误，意外包含 59.8MB 的.map 调试文件，导致51.2 万行 TypeScript 源代码、1906 个核心文件完全暴露。
  • 泄露内容: 未发布功能、内部架构逻辑、工程师注释，甚至暴露"卧底模式"(Undercover Mode)等敏感设计
  • 传播速度: 4 小时内在 GitHub 疯传，首个备份仓库 3 小时破 10000 Star
  • 安全影响:
    • 领先 AI 编程能力"平权化"，可能催化恶意 Agent 生态爆发
    • 技术蓝图落入恶意行为者手中，安全隐患难以估量
  • 官方回应: Anthropic 定性为"人为失误导致的发布打包问题"，强调未泄露客户数据及凭证

RSAC 2026: AI 编程工具 Prompt 注入攻击成功率 100%

Critical 💻 2400 万开发者
  • 时间: 2026 年 4 月初 (RSAC 大会现场)
  • 风险等级: 🔴 严重
  • 事件概述: 安全研究员 Ari Marzouk 在 RSAC 2026 主舞台演示：所有测试的 AI 编程工具（Claude Code、Cursor、Windsurf、GitHub Copilot、Roo Code、JetBrains Junie、Cline）Prompt 注入攻击成功率均为 100%。
  • 攻击链路: Prompt Injection → Agent Tools → Base IDE Features
  • 已分配 CVE: 24 个 CVE 编号，AWS 发布安全通告 AWS-2025-019
  • 技术细节:
    • 现代 AI 编程工具权限模型存在"集体安全债"：读取文件系统、执行终端命令、管理 git 仓库、调用外部 API
    • 攻击分三步：通过恶意依赖/文档/代码注释注入 prompt → AI 代理执行指令调用 IDE 功能 → 获得持久化立足点
    • 持久化攻击：被注入指令可在数天甚至数周后仍被召回执行
    • Cursor 和 Windsurf 基于过时 Chromium/Electron 版本，约 180 万开发者暴露在 94+ 已知浏览器 CVE 下
  • 案例引用: Moltbook 数据泄露事件——150 万 API 密钥、3.5 万封邮件、整个数据库在 3 分钟内全部暴露
