LiteLLM 供应链投毒事件 — AI 开发圈重大安全危机

Critical 🌍 AI 开发社区
  • 时间: 2026 年 3 月 24 日爆发
  • 风险等级: 🔴 严重 (CVSS 9.8+)
  • 事件概述: 黑客组织 TeamPCP 通过入侵 Trivy 安全扫描工具，窃取 LiteLLM 发布密钥，向 PyPI 发布包含恶意代码的版本 (1.82.7/1.82.8)。恶意文件使用双重 Base64 编码混淆，可导致内存耗尽、进程无限复制。
  • 影响范围: AI 开发社区广泛使用的 LLM 代理库，PyPI 已在 3 小时内隔离问题版本
  • 攻击特征: 供应链攻击 + 代码混淆 + 社区舆论操控 (73 个账号 102 秒内刷 88 条噪音回复)
  • 修复建议:
    • 立即检查项目中 LiteLLM 版本，降级至 1.82.6 或以下
    • 轮换所有可能暴露的 API 密钥
    • 审查 CI/CD 流水线中的 Trivy 集成
LiteLLM 供应链攻击 PyPI 投毒 TeamPCP CVSS 9.8+

Microsoft Copilot 零点击数据外泄漏洞 (CVE-2026-26144)

Critical 💼 企业用户
  • 时间: 2026 年 3 月补丁日修复
  • 风险等级: 🔴 严重
  • 事件概述: Excel 输入净化漏洞与 Copilot Agent 结合，形成新型 AI 驱动数据窃取攻击。攻击者可通过恶意 Excel 文件操控 Copilot 代理，实现零点击数据外泄。
  • 攻击范式转变: 从"攻击用户" → "操控 AI 代理执行攻击"
  • 核心特征: 零点击、无需权限提升、AI 作为执行主体、合法流量完成数据外泄
  • 影响: 可窃取 Excel 业务数据、凭证 Token、企业内部信息
  • 修复建议: 立即应用 2026 年 3 月 Patch Tuesday 更新
CVE-2026-26144 Microsoft Copilot 零点击 AI 代理攻击

OpenClaw 网关 WebSocket 无认证升级漏洞 (CVSS 10.0)

Critical 🌐 46.9 万实例
  • 时间: 2026 年 3 月 22 日披露
  • 风险等级: 🔴 致命 (CVSS 10.0)
  • 事件概述: 360 安全云团队发现 OpenClaw Gateway 核心零日漏洞，使用共享令牌时系统未正确验证客户端声明的权限范围，攻击者可声明高权限作用域完全控制网关中枢。
  • 暴露面: 互联网可探测 OpenClaw 实例超 46.9 万个，85% 直接暴露公网
  • 危害: 完全控制消息路由、Agent 调度、权限管理；可执行 Shell 命令、窃取敏感数据、植入后门
  • 修复建议:
    • 立即检查网关暴露面，禁止公网直接访问
    • 升级至最新安全版本
    • 启用严格的作用域验证机制
OpenClaw CVSS 10.0 WebSocket 360 安全云 46.9 万暴露

Citrix NetScaler 严重漏洞 (CVE-2026-3055) 遭活跃探测

High 🏢 企业网络
  • 时间: 2026 年 3 月 29-30 日
  • 风险等级: 🟠 高危 (CVSS 9.3)
  • 事件概述: Citrix NetScaler ADC/Gateway 中 SAML IDP 内存越读漏洞正遭攻击者活跃探测，可能导致敏感数据泄露。
  • 历史参考: 2023 年 CVE-2023-4966 "CitrixBleed"同类漏洞从披露到大规模利用仅数周
  • 修复建议:
    • 立即检查配置：`show run | grep samlIdPProfile`
    • 应用官方补丁 (CTX696300)
    • 部署 WAF 提供虚拟补丁防护
CVE-2026-3055 Citrix NetScaler SAML 内存越读

Xygeni Action 标签投毒漏洞 (CVE-2026-31976)

High 🔗 CI/CD
  • 时间: 2026 年 3 月 3 日披露
  • 风险等级: 🟠 高危 (CVSS 9.4)
  • 事件概述: GitHub 可变标签机制设计缺陷被利用，攻击者盗用 Xygeni 官方 GitHub App 私钥，将 v5 标签从安全版本强制指向恶意提交。
  • 影响范围: 1.2 万家企业、3.5 万个 GitHub 仓库的 CI 工作流
  • 攻击链: 标签篡改 → 代码执行 → 凭据窃取 → 云资源沦陷
  • 修复建议:
    • 检查所有引用 xygeni/xygeni-action@v5 的工作流
    • 使用固定提交哈希替代可变标签
    • 轮换 GITHUB_TOKEN 及云平台凭据
CVE-2026-31976 Xygeni 标签投毒 GitHub Actions 1.2 万企业

Ollama 默认配置安全隐患遭国家通报

Medium 🖥️ 本地部署
  • 时间: 2026 年 3 月下旬
  • 风险等级: 🟡 中危
  • 事件概述: 国家网络安全通报中心发布通报，Ollama 默认配置存在未授权访问与模型窃取隐患。本地部署默认开放 11434 端口且无鉴权机制。
  • 风险点:
    • 未授权访问模型服务
    • 通过/api/show 接口提取模型数据
    • 算力盗取与服务中断
  • 影响: DeepSeek 等大模型私有化部署用户
  • 修复建议:
    • 限制 11434 端口仅本地访问
    • 配置防火墙阻断公网出入站流量
    • 启用 API 密钥管理与 IP 白名单
